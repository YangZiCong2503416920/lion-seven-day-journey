# 《东陂的天空——红色南粤 · 冯达飞》交互网页

打开 `index.html` 即可预览。移动优先的纵向滚动叙事 H5，以 **“红色南粤 · 冯达飞”** 为叙事主轴，把岭南非遗、乡村科创收拢到 **“沿着冯达飞的航线继续飞”** 的线索下——不再是“四门课的清单”，而是“一位连州人的出行与归来 + 一代人的延续”。

## 已实现

- 移动端优先纵向滚动，顶部章节导航 + 故事进度条；
- 首屏 hero：**东陂的天空** + 副标题“红色南粤 · 冯达飞” + 金色数据带 + 队徽 + 逐字入场；
- **冯达飞生平时间线**（1901 东陂 → 1924 黄埔 → 1932 漳州 → 1942）：把“红色”落到具体年与地，回应“太笼统”；
- 四条航段（对应四类非遗/科创，全部含可交互）：
  - **01 根 · 从东陂镇醒来**（醒狮）→ 点醒醒狮（三声鼓）；
  - **02 脉 · 把颜色染进信仰**（扎染）→ 捆扎 → 浸染 → 解开看纹；
  - **03 翼 · 一张地图，一个方向**（水火箭）→ 打气 → 发射（含孩子愿望随机句）；
  - **04 归 · 飞回东陂的天空**（数字人 + 来信）→ 听数字人讲一段 / 翻开红色来信；
- 红色南粤：冯达飞 1901 生于东陂镇、1924 黄埔军校一期、参加北伐、1927 入党并先后参加南昌/广州起义、赴苏联学航空、回国任红军/人民军队飞行教官（“红军史上首位飞行员、人民军队航空先驱、空军首位飞行教官”）、1932 随红军攻占漳州驾驶缴获飞机首飞中央苏区、1942 在新疆牺牲（名字刻入空军英烈墙）等可核验史实线索；“没有导航、只有一张地图一个方向”仅作数字人讲述/画面意境，不写入正式史实口径；
- **传播引擎**：「为连州孩子，留下一句‘飞出去’的祝福」→ 输入祝福，生成专属纸飞机分享卡片（Canvas 出图 + 分享/复制）；
- **合规**：队徽（topbar + 结尾落款）、学校/学院/实践队署名、AI 辅助生成标注（含“基于公开史实的艺术化演绎，非真实历史影像/录音，不虚构原话”）、`og:*`/微信分享 meta、`prefers-reduced-motion` 降级；
- **命门修复**：`.reveal` 默认 `opacity:1`，入场用 transform+blur——整页截图绝不空白（附件4 页面截图评审安全）。
