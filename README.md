# 《飞出去——红色南粤 · 冯达飞 × 连州市实验小学》交互网页

打开 `index.html` 即可预览。移动优先的纵向滚动叙事 H5，以 **“红色南粤 · 冯达飞”** 为唯一叙事主轴，并用 **连州市实验小学“航天筑梦、党建筑魂”** 的精神风貌，接住冯达飞的“飞行与信仰”——不再是“非遗+科创+AI”的拼盘，而是一条“飞”与信仰的完整航线。

## 版本说明（v2.1 学校层 · 纯红色南粤）

  - 空 1932 随红军攻占漳州，驾缴获飞机首飞中央苏区（人民军队首次由己方飞行员驾机飞回红色根据地）；
  - 殁 1942.6 江西上饶集中营（茅家岭）壮烈牺牲，名字镌刻中国人民空军英烈墙；
